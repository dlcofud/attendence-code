# 개설과목 목록 갱신 (core 팀, 학기마다 1회)

`data/courses.json` 은 업로드 화면의 **과목·분반 선택기**가 쓰는 목록입니다.
"자료"만 쳐도 자료구조가 뜨고, 그 아래 분반을 스크롤해서 고를 수 있습니다.
목록에서 고른 과목은 `학수번호-분반`(예: `COSE213-02`)으로 세션이 묶이기 때문에 오타로 세션이 갈라지지 않습니다.

## 갱신 방법

1. https://sugang.korea.ac.kr → 왼쪽 메뉴 **과목조회 → 학부 과목조회** (로그인 불필요)
2. `F12` → **Console** 탭 → `tools/courses/collect.js` 내용을 붙여넣고 Enter
   - 파일 위쪽의 `YEAR`, `TERM`(1R/1S/2R/2W), `CAMPUS`(1 서울 / 2 세종)를 먼저 확인
3. 3~6분 뒤 `courses.json` 이 다운로드됩니다
4. 저장소의 `data/courses.json` 을 교체하고 커밋

## 파일 형식

```json
{
  "term": "2026-2학기",
  "campus": "서울",
  "source": "고려대학교 수강신청시스템 > 과목조회 > 학부 과목조회",
  "generated_at": "2026-11-02T11:00:00.000Z",
  "fields": ["code", "section", "name", "prof", "time", "dept", "type", "credit"],
  "rows": [["COSE213", "02", "자료구조", "교수명", "월(3-4) 강의실", "컴퓨터학과", "전공필수", "3"]]
}
```

용량을 줄이려고 행을 배열로 저장합니다. 열 순서는 `fields` 를 따릅니다.

## 참고

- 대학원 과목은 포함하지 않습니다(학부만). 목록에 없는 과목은 화면에서 "직접 입력"으로 올릴 수 있습니다.
- 수집기는 페이지의 "조회" 버튼을 직접 눌러 결과를 모으고, 요청 사이에 쉬는 시간을 둡니다. 수강신청 기간처럼 서버가 붐빌 때는 실행하지 마세요.
